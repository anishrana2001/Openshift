## Helm chart repo has been shared on gitlab `https://git.ocp4.example.com/developer/devops-wala.git`

For **Lab environment**, fulfill the below requirement.
- Deploy the application to the project `lab-customer-red`
- Use the Helm release name `lab-static-webserver`
- Use the template file `devops-wala/static-webserver/lab-customer-red.yaml`
- Set the image repository to `registry.ocp4.example.com:8443/redhattraining/hello-world-nginx:v1.0`
- Set the label `stage to lab`
- Configure the application resource **limits** `CPU: 250m` and  `Memory: 512Mi`
- Increase the number of Pods to `2`
- Secure the public access to the application using `TLS`
- Set application name to `lab-webserver`
- Application listens on port `8080`
- Set environment variable `ENVIRONMENT=LAB`

For **production environment**, fulfill the below requirement.
- Deploy the application to the project `production-customer-red`
- Use the Helm release name `production-static-webserver`
- Use the template file `devops-wala/static-webserver/production-customer-red.yaml`
- Set the image repository to `registry.ocp4.example.com:8443/redhattraining/hello-world-nginx:v1.0`
- Set the label `stage to production`
- Configure the application resource **limits** `CPU: 350m` and  `Memory: 712Mi`
- Increase the number of Pods to `4`
- Secure the public access to the application using `TLS`
- Set application name to `production-webserver`
- Application listens on port `8080`
- Set environment variable `ENVIRONMENT=PRODUCTION`
