# Q1 — Build and Deploy `todo-ssr` on OpenShift

## Question

The application must be built and deployed from the source code at:
`https://git.ocp4.example.com/developer/DO288-apps`

- The application source code is located in the subdirectory:
`apps/compreview-todo/todo-ssr`

- The application must be deployed to the project **`deploy-cli`**
- The deployed application and its resources must be named **`todo-ssr`**
- The application must be based on the image stream tag **`httpd:2.4-ubi9`**
- The application's dependencies are available at:
http://nexus-infra.apps.ocp4.example.com/repository/npm


- The Git server requires authentication using the following credentials:
  - **Username:** `developer`
  - **Password:** `d3v3lop3r`

---

## Hint

> You can pass the Nexus path to the build environment using the following build environment variable:
> ```
> npm_config_registry
> ```
> The Git credentials must be provided as a **secret** and linked to the **builder** service account **before** creating the application, so that the build pod can authenticate to the Git server during the source clone phase.

---

## The application must be accessible using both:
http://todo-ssr.apps.ocp4.example.com 
https://todo-ssr.apps.ocp4.example.com



---

## ✅ Solution

### 1️⃣ Create the Git Secret
```bash
oc create secret generic gitlab-secret \
  --from-literal=username=developer \
  --from-literal=password=d3v3lop3r \
  --type=kubernetes.io/basic-auth
```
###  Annotate the Secret with Git Server URL
```
oc annotate secret gitlab-secret \
  "build.openshift.io/source-secret-match-uri-1=https://git.ocp4.example.com/*"
```

### Link the Secret to the Builder Service Account
```
oc secret link builder gitlab-secret
```

### Create the Application
```
oc new-app \
  --name=todo-ssr \
  --build-env npm_config_registry="http://nexus-infra.apps.ocp4.example.com/repository/npm" \
  httpd:2.4-ubi9~https://git.ocp4.example.com/developer/DO288-apps \
  --context-dir=apps/compreview-todo/todo-ssr
```

### Expose the Application via HTTP
```bash
oc expose service/todo-ssr \
  --hostname=todo-ssr.apps.ocp4.example.com
```

### Expose the Application via HTTPS
```
oc create route edge \
  --service=todo-ssr \
  --hostname=todo-ssr.apps.ocp4.example.com
```

### Verify
```
# Check build status
oc get builds

# Check all resources
oc get all
```
# Check routes
oc get routes
```
